One haiku about debugging, in the classic 5-7-5 shape — seventeen syllables, three lines, read in one breath.

> Cursor blinks at three
> the log still says nothing new
> turns out it was me

`main.ts` (Node 22, stdlib only) writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then reads it back and throws if it differs byte-for-byte.
